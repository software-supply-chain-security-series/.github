The **Software Supply Chain Security Series** is a series of the
[Joint Development Foundation](https://jointdevelopment.org/), part of the
Linux Foundation. Our mission is **to publish open standards for widely used
software supply chain security technologies.**

🌐 **Website:** <https://software-supply-chain-security-series.github.io/>

## Projects

| Project | What it is | Working group |
|---|---|---|
| [The Update Framework (TUF)](https://theupdateframework.io/) | A framework for securing software update systems, resilient to key and repository compromise | [tuf-wg](https://github.com/software-supply-chain-security-series/tuf-wg) |
| [in-toto](https://in-toto.io/) | A framework for verifying the integrity of the software supply chain end to end | [in-toto-wg](https://github.com/software-supply-chain-security-series/in-toto-wg) |
| [Uptane](https://uptane.org/) | A security framework for over-the-air updates in automobiles and embedded systems | [uptane-wg](https://github.com/software-supply-chain-security-series/uptane-wg) |
| [DSSE](https://github.com/secure-systems-lab/dsse) | Dead Simple Signing Envelope, a simple, secure format for signing arbitrary data | [dsse-wg](https://github.com/software-supply-chain-security-series/dsse-wg) |

More projects are joining the series soon.
